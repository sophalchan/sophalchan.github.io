# Sophal Chan — Quarto Portfolio

Professional portfolio site (Cybersecurity · AI/ML · Data Analytics) built with [Quarto](https://quarto.org/) and deployed to GitHub Pages.

## Project structure

```
.
├── _quarto.yml              # Site & navbar configuration
├── index.qmd                # Homepage with project grid + filters
├── about.qmd                # Trestles profile layout
├── styles.css               # Custom theme overrides
├── posts/
│   ├── cyber-threat-ids/
│   ├── geospatial-anomaly-dashboard/
│   └── network-traffic-lab/
├── assets/                  # profile.jpg, project images
├── docs/                    # Rendered site (generated by quarto render)
└── .github/workflows/       # CI deploy to GitHub Pages
```

## Before you publish

1. Replace `YOUR_LINKEDIN_SLUG` in `_quarto.yml` and `about.qmd` with your LinkedIn profile slug.
2. Add `assets/profile.jpg` (see `assets/README.md`).
3. Site URL: `https://sophalchan.github.io/`
